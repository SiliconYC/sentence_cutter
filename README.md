# 句子粗剪器 (Sentence Cutter)

一款基于 SRT 字幕文件，通过编辑句子的方式来快速对视频进行粗剪的桌面应用程序。

## 核心理念

传统的视频剪辑依赖于在时间线上反复拖动、预览和切割，过程繁琐且耗时。对于以对话、旁白或课程为主的长视频而言，其核心内容结构早已体现在字幕文件中。

“句子粗剪器”的核心理念是：**将视频剪辑转化为文本编辑**。

用户不再需要操作复杂的时间线，而是像在文本文档中删除段落、调整语序一样，通过勾选、排序字幕卡片来直观地完成视频的筛选和重组，从而实现分钟级别的快速粗剪。

## 工作流程

本软件的工作流程被设计为清晰的三步式：

1.  **创建 (Create)**：在开始界面，指定一个工作目录并由程序完成项目初始化。软件会自动检查必要的素材（视频和 SRT 文件）是否齐全。
2.  **筛选 (Select)**：初始化完成后，软件会将每一句字幕生成一张可视化的卡片。在此界面，您可以像处理待办事项一样，快速勾选您需要保留的句子片段。
3.  **排序 (Sort)**：所有被选中的句子会进入排序界面。您可以通过简单的拖拽或按钮操作，将句子按照您想要的最终顺序排列成一个新的序列。未被放入最终序列的句子将被自动舍弃。

完成排序后，点击一键导出，即可获得由保留的句子片段按新顺序拼接而成的完整视频，以及每个片段独立的素材文件。

## 主要功能

- **字幕驱动剪辑**：直接通过字幕内容进行视频片段的选择与排序。
- **三步式引导**：通过“创建”、“筛选”和“排序”三个独立界面，引导用户清晰地完成剪辑流程。
- **可视化卡片**：每句字幕以卡片形式呈现，包含序号、时间码和文本内容，信息清晰明了。
- **素材片段导出**：除了最终成片，软件也会将每一个被选用的句子所对应的视频片段单独导出，方便用户在其他专业剪辑软件中进行精修或二次创作。
- **无损拼接**：最终的全片合成采用流复制（Stream Copy）模式，在保证极快合成速度的同时，避免了视频画质的二次压缩损失。

## 技术栈

- **前端框架**: Python + PySide6
- **UI 主题**: qt-material
- **核心处理**: FFmpeg (用于视频的解析、分割与合并)
