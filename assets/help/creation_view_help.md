# 第一步：“创建”页使用说明

欢迎来到句子粗剪器的第一步！这个页面的核心任务是**初始化项目**，为后续的剪辑工作准备好所有必要的素材和数据。

## 首次初始化

当您首次加载一个新创建的项目时，需要进行初始化。整个过程非常简单，只需两步：

1.  **准备素材**
    -   点击 **“打开素材目录”** 按钮。
    -   系统会自动为您打开项目中的 `01_Source` 文件夹。
    -   请将您需要剪辑的 **一个字幕文件（.srt）** 放入这个文件夹中。
    -   **注意**：为了程序能正确识别，请确保该文件夹内有且仅有一个字幕文件。视频文件在这一步是**可选**的，您可以在最后合成视频时再提供。

2.  **开始初始化**
    -   当您放置好文件后，返回软件界面，点击 **“开始初始化”** 按钮。
    -   程序会开始解析字幕内容，并将这些基础数据保存在项目的 `02_Intermediate` 文件夹中。
    -   如果一切顺利，您会看到一个成功的提示，然后软件会自动跳转到下一步——“筛选”页面。

## 再次加载项目

如果您关闭软件后重新打开同一个项目，程序会自动加载上次解析好的数据。

-   **如果加载成功**：您会发现底部的 **“下一步”** 按钮是可用的，可以直接点击进入“筛选”页，无需再次初始化。您的所有筛选和排序进度都会被保留。
-   **如果加载失败（或您想更新素材）**：您可以随时点击 **“开始初始化”** 来重新解析 `01_Source` 文件夹中的字幕文件。

## 可能遇到的问题

-   **初始化失败**：最常见的原因是 `01_Source` 目录中的文件不符合要求（例如，没有字幕文件、多于一个字幕文件等）。请根据弹出的错误提示检查您的文件。
-   **重复初始化警告**：如果您在一个已经有进度的项目中点击“开始初始化”，程序会弹出警告。请注意，**重新初始化会清空您在“筛选”和“排序”页面的所有选择和排序记录**，因为它是基于全新的字幕来生成数据的。
