# 第二步：“筛选”页使用说明

这是剪辑流程的核心步骤。在此页面，您可以像处理文本一样，快速浏览并挑选出您需要保留的视频片段。

## 核心操作：选择卡片

每一张卡片代表一句字幕及其对应的视频片段。您可以通过鼠标进行快速选择或取消选择。

- **选中**：按住 **鼠标左键** 并从一张卡片拖动到另一张，所有经过的卡片都会被设为“选中”状态。
- **取消选中**：按住 **鼠标右键** 并拖动，所有经过的卡片都会被“取消选中”。
- **单击**：单击一张卡片只会改变当前卡片的选择状态。

### 快捷键：Shift 范围选择

为了更高效地操作，您可以配合 `Shift` 键进行大范围选择：

1.  首先，通过单击或拖拽，让任意一张卡片获得黄色的高亮框（这代表“光标”位置）。
2.  然后，按住键盘上的 `Shift` 键不放。
3.  用 **鼠标左键** 点击另一张卡片，系统会自动选中从“光标”位置到您点击位置之间的所有卡片。
4.  用 **鼠标右键** 点击另一张卡片，则会取消选中该范围内的所有卡片。

## 顶部工具栏

页面顶部提供了一套工具来帮助您快速定位和操作：

- **跳转到光标**：无论列表滚动到哪里，点击此按钮都会立刻将视图定位到当前带黄色高亮框的卡片。
- **跳转到序号**：输入卡片左侧的 `#` 后面的数字（例如 `123`），按回车，即可跳转到指定卡片。
- **跳转到时间**：输入时间码（支持 `HH:MM:SS.ms` 或纯秒数 `SSSS.ms` 格式），按回车，即可跳转到该时间点所在的卡片。
- **全选/清空**：快速选中或取消所有句子的勾选状态。
- **关键词搜索**：在最右侧的输入框中输入关键词并按回车或“搜索”按钮，可以高亮所有包含该关键词的卡片。重复点击“下一个”按钮可以在搜索结果之间循环跳转。
- **清空（搜索）**：清除所有搜索框的内容和搜索结果。

## 撤销、重做与保存

- **撤销/重做**：您的每一次选择操作都会被记录下来。
    - 使用快捷键 `Ctrl + Z` (Windows/Linux) 或 `Cmd + Z` (macOS) 可以 **撤销** 上一步操作。
    - 使用快捷键 `Ctrl + Y` (Windows/Linux) 或 `Cmd + Shift + Z` (macOS) 可以 **重做** 已撤销的操作。
- **保存**：您的所有编辑进度（包括此页的选择和下一步的排序）都会被自动或手动保存。
    - **手动保存**：随时按下 `Ctrl + S` 或点击菜单栏的“文件”->“保存”。
    - **自动保存**：在切换项目或关闭软件时，程序会自动为您保存进度。

## 底部状态栏

页面底部会实时统计您已选中的卡片信息，包括总句数、总时长、总字数等，方便您随时评估工作量。
